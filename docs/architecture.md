# Architecture

The self-contained SKILL.md holds identity, evidence discipline, ten modes, operational workflow, camera/light/action/sound, Brazilian dialogue, continuity, output contract, error handling and quality review. References deepen individual techniques; examples are authored specifications, not observed original-agent outputs.

The source brief is preserved separately for traceability. Tests encode prompts and expected assertions. Structural validation checks metadata, required paths, links, case IDs, example dialogue, headings and continuity-example count. It cannot certify semantics or render fidelity.

No mandatory runtime service, API adapter, hidden configuration, provider token or persistent memory layer is implemented. External integration is optional and must be real before claimed.
