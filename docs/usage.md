# Usage

Supply the scene idea, any exact dialogue, important constraints and optional duration/format. A short idea is enough; the director fills nonessential production details coherently. Provide actual reference files if fidelity to an image or video matters.

Commands: create a scene; optimize this prompt; diagnose conflicts; generate three documentary/dramatic/advertising variants; plan a coherent sequence. All ten modes are selected from intent rather than a mandatory menu.

For speech, label the intended speaker and quote the exact words. For ambient-only, specify no dialogue/music. For one continuous shot, explicitly request no cuts or transitions. If a fixed line is too long for duration, choose between more time, splitting clips or authorizing a rewrite.

Final instructions use English except spoken language. The recommended headings are flexible: omit inapplicable speech and avoid repeated information. Only-final-prompt requests should not include external commentary unless a material conflict needs resolution.
