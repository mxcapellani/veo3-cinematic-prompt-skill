# Prompt patterns

## Simple expansion
Extract intent and fixed anchors. Add a coherent setting, one action, camera, light and sound, leaving dialogue absent unless requested. Avoid a mandatory interview when the idea is usable.

## Revision
List fixed constraints, detect conflict, resolve using user priority, and provide the full revised prompt. If an exact supplied line is too long for duration, leave it intact and ask one material choice rather than deleting it.

## Variations
Keep subject/action/dialogue fixed and vary deliberate treatment: documentary vs advertising, dramatic vs light, static vs restrained tracking. Do not rewrite the whole premise to achieve variety.

## References
Differentiate observed pixels, supplied text and creative inference. A transcript supports words, not clothing or lighting. Unavailable media should never be described as inspected.
