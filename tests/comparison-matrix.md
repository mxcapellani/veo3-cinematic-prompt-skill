# Paired comparison

Apply exactly the same test-cases.json inputs, frozen prior context and assets to the original agent and the Skill. Record host/model, date, version and available generation settings. Repeat non-deterministic cases at least three times without selecting only the best run.

For each case record original output, Skill output, per-dimension scores, delta, result, evidence, regression and notes. Compare functional satisfaction, not literal wording where both outputs meet the contract. Original-agent output is currently unavailable; all paired cases remain NOT EXECUTED.

Where video quality is assessed, render both prompt sets in the same generator with matched reference assets and settings; inspect dialogue, lip-sync, visual continuity and sound. Without actual renders, those outcomes are NOT VERIFIABLE rather than approved. Separate text quality from generator limitations.

Use evaluation-rubric.md for dimensions and status definitions. Do not declare absolute parity from a partial suite. Update audit and changelog with actual findings, preserving failed and blocked cases.
