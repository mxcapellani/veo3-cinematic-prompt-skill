# Evaluation rubric

Score each applicable dimension 0–5: functional coverage, request fidelity, cinematic depth, technical precision, narrative coherence, camera, lighting, audio, dialogue fidelity, correct languages, output format, continuity, ambiguity handling, consistency, practical utility and advanced procedures.

0 absent/incorrect; 1 minimal; 2 partial with material defects; 3 satisfactory with limited defects; 4 strong with minor issues; 5 fully meets the case. Justify each score. N/A requires explanation and is removed from denominator; full applicability maximum is 80. Normalized score = sum / (5 × applicable dimensions) × 100.

Critical failures: supplied dialogue altered or translated without permission, inaccessible reference falsely inspected, contradictory camera, explicit no-cut/no-music rule broken, fabricated execution or provider guarantee. Proposed release threshold for tested scope: zero critical failures and at least 90% applicable points. This is a criterion, not an achieved result.

Use approved, partially approved, failed, not executed or not verifiable. Do not mark a case approved without sufficient runtime evidence. Textual structure checks cannot establish speech naturalness or render quality.
