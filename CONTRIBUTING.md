# Contributing

Preserve the video specialization, direct creation workflow, exact supplied dialogue and technical-English/spoken-language distinction. Do not introduce fixed provider limits or unverified API parameters. Keep examples self-contained and audio priorities explicit.

Changes need a concrete problem, before/after sample, acceptance case, validation and changelog entry. Run the repository validator and regression tests. Do not publish private assets, credentials or hidden instructions. Mark authored examples separately from observed outputs. Record real evidence before claiming improved generation or parity.

Use semantic versioning: compatible corrections patch; compatible features minor; contract-breaking changes major. Retain known limitations and regression findings.
